---
name: verify-j4
description: Проверка готовности World Bundle J4 после ревью J3b/J3c.
---

Проверь входы J4 по [плану](../plans/error-contracts-1.md) §6.1. Учитывай вердикты J3b/J3c, принятый EC-11 и закрытый R-J4-1. Если вход остаётся открытым, назови его; доступные независимые проверки выполни.

Проследи импорт от HTTP и WorldBundleService до транзакции WorldCopyImport. Для каждого критерия укажи доказательство на текущей ревизии: preview без записи и резервирования, совпадение причин в preview и HTTP 422 там, где контракт одинаков, полный wire loc, повторная проверка после remap, rollback и continuation. Для ошибки инфраструктуры и отмены проверь отдельный исход. Используй существующие test_import_validation_policy, test_declared_region_edit и test_library_packs_4d; повторно запускай сценарии, если доказательств для текущего кода недостаточно.

Результат: проверенная ревизия, выполненные тесты, вердикт по каждому критерию и рекомендация по приёмке J4. Не исправляй код и не присваивай статус принятия от имени владельца.
