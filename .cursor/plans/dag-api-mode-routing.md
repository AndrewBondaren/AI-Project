# DAG-ROUTING-1 — Маршрутизация входящих сообщений по API-флагам

**Статус:** отдельная задача / к проектированию.  
**Владелец решения:** DAG Engine и входной API-контракт.  
**Граница:** задача не относится к возможностям LLM-роли/ноды `TECHNICAL`; не изменяет ID-9 и ТЗ LLM-ролей.

## Задача

Спроектировать маршрутизацию входящего сообщения на уровне DAG Engine:

- API передаёт явные флаги/параметры режима взаимодействия (например, игровое действие, метагейм, обсуждение сессии). Точные имена, типизация, значения и default требуют отдельного согласования.
- DAG Engine интерпретирует разрешённые API-флаги и состояние исполнения **до выбора следующего маршрута**. Он решает, должен ли запрос пройти через техническую LLM-ноду или сразу перейти в иной сценарий DAG.
- Техническая LLM-нода **не определяет режим взаимодействия, не переключает его и не отвечает за маршрутизацию**. Она исполняется только если выбрана самим DAG Engine.
- Отдельно проверить стык с существующим `ChatRequest.task_type` (сейчас может обходить `INTENT_DETECTION`), `meta`, pass/replan, cancel/resume и правами контекста. API-флаг не должен сам по себе повышать уровень доступа к данным.
- Формализовать ожидаемые переходы и негативные сценарии, затем согласовать решение с мастером до изменений движка.

## Критерии дальнейшей проработки

- [ ] Определён типизированный API-контракт режимов/флагов и его допустимые значения.
- [ ] Описано, когда DAG Engine выбирает техническую ноду, а когда выполняет прямой переход.
- [ ] Определены приоритеты флагов, `task_type`, текущего состояния и правил replan/resume.
- [ ] Подготовлены тест-кейсы для маршрутов, отмены/возобновления и недопустимых флагов.
- [ ] Отдельно получено разрешение на реализацию в API/DAG.

## Не входит в задачу

- Изменение состава, знания, DSL, Output и других возможностей роли `TECHNICAL` или `INTENT`.
- Изменение группировки LLM по ролям/temperature.
- Автоматическая LLM-классификация режима и принудительный LLM-вызов перед маршрутизацией.
- Код, миграции и изменение действующих DAG-нод на этапе этой фиксации.
