# Lifecycle: цепочки переходов с пересечением участников

Дата: 2026-11-21. По поручению пользователя создан отдельный план расширения. Статус: OPEN / проектирование; реализация не разрешена. Вне scope основного [плана Lifecycle](entity-lifecycle.md). SoT: [ТЗ](../../docs/tz_entity_lifecycle.md).

## Цель

Спроектировать возможность нескольких переходов одной сущности внутри одной атомарной публикации с явными промежуточными состояниями. Создание плана не принимает конкретную реализацию или новый порядок DAG.

## Сценарии для согласования

- Create C → Replacement C,D → E в одной публикации.
- End A → Reactivate A с сохранением обоих событий, если предметный домен допускает это.
- Несколько последовательных Replacement с общими участниками.

## Обязательные решения до реализации

1. Явные связи предшествования переходов; ordinal не является доказательством порядка состояний.
2. Типизированные intermediate before/after, непрерывность цепочки, отсутствие циклов и неоднозначных предшественников.
3. Предметное evidence каждого промежуточного перехода; итогового состояния недостаточно без согласованного доказательства.
4. Identity/retry/conflict всего набора и отдельных change_uid, history/projection/receipt mapping.
5. Exact публичные классы, Input/Output/Error, внутренние реализации, зависимости и ответственность каждого класса. Пока OPEN, классы и ноды не назначаются.
6. Атомарное применение всей цепочки, ошибки и unknown outcome; нельзя автоматически разбивать на разные публикации или сворачивать историю.
7. Проверка междоменной цепочки координатором Between domain operations и решение пользователя.

## Критерии приёмки

Для каждого сценария показать базу, все intermediate states, предметные доказательства и итог. Проверить отказ на разрыв before/after, цикл, конфликт UID и неполное coverage. История содержит все принятые переходы, проекция соответствует конечному состоянию, частичная публикация запрещена. Выполнить все обязательные критерии DAG и class-by-class ответственность до реализации полной архитектуры расширения. Текущий запрет пересечений не снимается до отдельного согласования.
