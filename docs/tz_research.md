# ТЗ: Исследования и знания (research / discovery) — универсальная механика изучения

**Статус:** draft — **не проработано** (концепция зафиксирована 2026-10-19; семантика не утверждена, impl не начат).  
**Исходная позиция:** [`tz_product_vision.md`](./tz_product_vision.md) §1.9 «Магия и исследования» — исследование = семантическая проверка гипотезы на правилах мира; игрок не создаёт закон прозой, а открывает неизвестный аспект существующих законов.

## Назначение

Единая механика **изучения законов мира**: магия, наука, технологии, алхимия и другие авторские домены — частные случаи одной машины. Субъект исследования — любой агент: игрок, essential NPC, фракция, поселение. Результат — знание субъекта (не глобальный unlock).

## Концептуальная модель (черновик)

Три слоя; каждый — отдельная развилка в § Открытые вопросы.

### Слой 1. Корпус законов мира (author-side, SoT)

Проверка гипотезы «на основе правил мира» требует формализованных правил. N+1-реестр законов:

- домен (`magic` / `physics` / `metallurgy` / `alchemy` / …) — авторский, расширяемый;
- утверждение + предпосылки + следствия → граф импликаций;
- существующий зачаток: ID-16 (источники магической энергии существо/мир) — первый записанный «закон» такого вида.

Глубина формализации — главная открытая развилка (Q1): полностью структурный корпус (rule engine, движок выводит следствия) vs полуструктурный (NL-формулировка + формальные hooks/FormulaNode на проверяемых эффектах).

### Слой 2. Hypothesis → experiment → verdict (engine-side)

| Режим | Что | Свойства |
|---|---|---|
| **Curated** | автор объявляет discoverables — узлы «что можно открыть» с условиями (требуемые знания, материалы, тип эксперимента) | предсказуемо, сюжетно контролируемо; семантическое tech-tree |
| **Derivative** | гипотеза = структурное высказывание («материал A проводит энергию B при условии C»); движок проверяет выводимость из корпуса законов | свободные эксперименты; требует Q1-структурного корпуса |

Предполагаемая цель — **гибрид**: общий корпус законов; curated-узлы поверх для авторского контроля; derivative-проверка для свободных экспериментов.

Вердикт выносит **только движок**. LLM формулирует гипотезу и описывает эксперимент — не решает его исход.

### Слой 3. Знание субъекта (per-subject, субъективное)

Каноническая истина живёт в движке; у субъекта — запись знания:

- источник: собственный эксперимент / книга / рассказ NPC / слух;
- возможна **искажённая** версия — ложное знание как законный результат (неудачный эксперимент, деградация при пересказе);
- укладывается в существующую модель ID-1 (Facts/Beliefs), ID-2 (слухи), ID-13/ID-15 (per-observer представление canonical-фактов, память ограничена знаниями NPC);
- каналы распространения: учение, книги, слухи, торговля → **диффузия** знания, а не мгновенный глобальный unlock.

## Субъекты исследования

| Субъект | Механизм |
|---|---|
| Игрок | полный цикл hypothesis → experiment → verdict в сцене |
| Essential NPC | тот же цикл; решения — фоновый LLM (`npc_llm_triggers`, см. `tz_lazy_simulation`) |
| Фракция / поселение | агрегатная симуляция дальней зоны: выделение ресурсов → абстрактный прогресс по curated-узлам, без пошаговых экспериментов |
| Диффузия | знание мира растёт через события/слухи/торговлю; один discoverable может быть открыт игроком экспериментально и фракцией фоново |

## Продуктовые сценарии (обоснование фичи)

**Параллельное открытие и ложная эксклюзивность.** Игрок и NPC-исследователь независимо приходят к одному выводу — открывают один и тот же тип магии. Канонически знание у двоих; у каждого в мета-знании — «единственный носитель». Через год игрок узнаёт слухом (ID-2), что NPC распространил «его» заклинание — emergent-конфликт приоритета без скриптов.

Требования, которые вытаскивает сценарий:

- **Параллельное открытие законно** — нет глобального mutex на discoverable; canonical-запись ведёт историю «кто и когда открыл», субъект её не видит.
- **Мета-знание** — belief о чужом знании/незнании («только я знаю», «магистр точно владеет этим»); слой поверх ID-1, открытый вопрос Q9.
- **Возврат диффузии к автору** — распространение по соцграфу достижимо и наблюдаемо для первооткрывателя (слух/событие о чужом владении «его» знанием).
- Смежные сценарии того же контура: шпионаж/похищение знания, приоритетные споры, монополия гильдии на технику, утрата знания (последний носитель умер).

## Инварианты (предварительные)

1. Вердикт эксперимента — только engine-side; LLM никогда не арбитр истины.
2. Знание — per-subject; глобального «все узнали» нет, распространение только через каналы.
3. Ложное знание — валидное состояние, не баг; canonical-истина не протекает в субъективные записи.
4. Домен исследования — N+1 авторский; механика не содержит веток «магия/наука» (как ID-17: причина отделена от универсальной механики).
5. Результат открытия материализуется объектом мира или записью знания — по решению Q5.
6. Параллельное открытие одного узла разными субъектами — штатный случай, не гонка и не ошибка.

## Антипаттерны

- LLM-арбитр: «убедительная проза = успешный эксперимент» — прямое нарушение §1.9.
- Глобальный tech-tree unlock: открытие субъектом ≠ знание всех субъектов.
- Знание только в LLM-контексте без engine-записи (дрейф, невозможность диффузии и проверок).
- Отдельные механики «магические исследования» и «научные исследования» с разным кодом — один домен-агностичный контур.

## Открытые вопросы

| # | Вопрос | Развилка |
|---|---|---|
| Q1 | Глубина формализации законов | rule engine (структурный вывод) vs полуструктурный корпус с проверяемыми hooks |
| Q2 | Discoverables | pre-authored узлы vs emergent-вывод vs два слоя (гибрид — рабочая гипотеза) |
| Q3 | Store знания | расширение модели памяти ID-13 (propositional knowledge как тип записи) vs отдельный store |
| Q4 | `is_discovered` локаций/ресурсов | частный случай knowledge-модели (spatial knowledge) vs отдельный флаг — сейчас семантика «субъект знает X» дублируется |
| Q5 | Результат открытия | материализация объекта мира (recipe/spell/tech unlock в реестре) vs только запись знания |
| Q6 | Частичные открытия | гипотеза верна при условиях → открытие с оговорками; модель представления |
| Q7 | Стоимость/время исследования | ресурсы, скиллы (`skill_schema` N+1), время; для фракций — агрегатная формула |
| Q8 | Неудачи | ничего / ложное знание / авария (событие с последствиями) — политика по доменам |
| Q9 | Мета-знание | beliefs субъекта о чужом знании/незнании («единственный носитель»): поле записи знания vs отдельная модель; как обновляется при слухах |
| Q10 | Attribution | canonical-история «кто открыл первым» — влияет ли на что-то (репутация, приоритетные споры) или только статистика |
