# Предварительные контракты фронтенда

`GameApi` описывает операции приложения. HTTP-маршруты, имена полей прежнего
бэкенда, формат запроса к модели и разбор SSE находятся в адаптере и транспорте.
Будущий бэкенд подключается через реализацию того же интерфейса.

## DTO

| DTO | Поля |
| --- | --- |
| Мир | `id`, `name` |
| Персонаж | `id`, `name`, необязательные `characterClass`, `gender`, `activeSession` |
| Активная сессия персонажа | `worldId`, `worldName` |
| Сессия в списке | `id`, `worldId`, `worldName`, `characterId`, `characterName`, `lastActiveAt` (ISO 8601) |
| Сообщение | `role`, необязательные `text`, `displayText` и `data` |
| Прерванное действие | `text`. Если прерванного действия нет, возвращается `null` |

Идентификаторы передаются строками. Имена связанных сущностей в сессии могут
быть `null` после удаления. Списки возвращают пустой массив при отсутствии данных.
`getHistory` возвращает сообщения по порядку, `limit: null` запрашивает всю историю.

`createSession(worldId, characterId)`, `copyCharacter(characterId)` и
`importCharacter(source)` возвращают `{ id }`. Импорт мира и удаление сессии
или персонажа подтверждаются завершением операции. Источник импорта —
либо `{ file: File }`, либо `{ path: string }` из Electron.

## Поток чата

`streamMessage` принимает `sessionId`, уникальный `requestId`, `message`,
необязательный `displayText` для подписи выбранного действия и `resume`.
`cancelMessage(requestId)` запрашивает отмену. UI читает типизированный
`AsyncIterable<ChatEvent>`.

| Событие | Поля | Назначение |
| --- | --- | --- |
| `status` | `phase`, необязательное `taskType` | Текущая стадия |
| `thinking` | `elapsedMs` | Время обработки в миллисекундах |
| `result` | `response` | Итоговый текст или структурированный ответ |
| `cancelled` | — | Подтверждение отмены, действие можно продолжить |
| `error` | `message` | Ошибка обработки действия |

Структурированные ответы включают `selectLocation` с `parent` и `children`
(варианты с `id`, `name` и необязательными `typeLabel`, `stateName`, `isHome`)
и `sceneReady` с `location: { name, description? }`. Неизвестный ответ
отображается как JSON. Адаптер преобразует старые события и структурированную
историю в этот формат.

При использовании SSE каждое событие передаётся отдельной строкой `data:`
с JSON и пустой строкой после неё. Ожидается завершение через `result`,
`cancelled` или `error`. Ошибка транспорта отклоняет запрос или прерывает
итерацию. Она показывается отдельно от игровых сообщений. Пустой список или
история отображаются после успешной загрузки.

Исходники контрактов: `src/shared/api/contracts.ts`,
`src/shared/types/records.ts`, `src/shared/types/chat.ts`.
